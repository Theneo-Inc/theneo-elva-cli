# Security reporting

Report suspected vulnerabilities privately to **support@theneo.io**. If this
repository has GitHub private vulnerability reporting enabled, you may also use
its Security → Report a vulnerability action. Avoid public issues for undisclosed
vulnerabilities.

Include the affected CLI version, workflow, impact and a minimal synthetic
reproduction. Redact tokens, verification codes, credential files, private API
specifications and customer data. Do not attach entire repository snapshots or
production logs. No response SLA or bounty is promised by this document.
